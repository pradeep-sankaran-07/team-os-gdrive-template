# Roadmap

**This file deliberately holds almost nothing.**

The roadmap lives in the work tracker and is queried live. A roadmap copied into
a Markdown file is stale within a week, and then there are two answers to the
same question and no way to tell which is current.

What belongs here instead: the handful of shaping decisions that are not tickets
and that a ticket would lose.

## Shaping decisions

| Date | Decision | Why |
|---|---|---|
| 2026-07-02 | Social is the second channel, not a parallel first channel | Running both from the start produced worse reply rates in every pilot, and made attribution unreadable |
| 2026-08-14 | Guardrails pause automatically rather than alerting | An alert that arrives while someone is asleep is not a guardrail |
| 2026-09-03 | We will not build our own CRM objects | Every deal already has a CRM, and sync beats replacement in each one we have lost |

## How to answer a roadmap question

Query the tracker. If someone asks what is shipping this quarter, that is a live
question with a live answer. If they ask why something is shaped the way it is,
that is this file.
