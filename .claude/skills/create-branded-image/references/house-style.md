# House photographic style

The look every Acme image shares. Replace this with your own during install;
what matters is that a house style exists in one file and every image is built
from it, rather than each request inventing a look.

**Palette.** Built from the brand tokens: a cool primary base, warm accent used
sparingly as a single point of interest, neutral greys everywhere else. Never
saturated, never neon.

**Light.** Soft, directional, single source. Gentle falloff. No hard studio
speculars, no lens flare.

**Composition.** Generous negative space, especially on the side where text will
sit. Subject off-centre. Shallow depth of field.

**Subject matter.** Work in progress rather than posed success: screens
mid-task, hands, desks, whiteboards, a room mid-conversation. No handshakes, no
stock-photo boardrooms, no arrows pointing up and to the right.

**What is never in an image.** Legible text of any kind, logos, trademarks,
identifiable faces of real people, flags, currency symbols.

**Aspect ratios by placement.**

| Placement | Ratio |
|---|---|
| Blog featured image | 16:9 |
| Social card | 1.91:1 |
| Square social | 1:1 |
| Slide background | 16:9 |
| Event panel | check the spec sheet; never guess |
