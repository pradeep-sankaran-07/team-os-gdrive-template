Run the `solution-brief` skill at `.claude/skills/solution-brief/SKILL.md` for the prospect named in $ARGUMENTS.

Pick exactly one value angle and have a human confirm it before drafting. Every number carries the assumption it rests on, on the page. Every claim about the prospect traces to a named call.

Boundary: a priced list of what they get is a different document, and no skill
for it ships with this template. An existing customer's review is `account-review`. Public marketing is `acme-marketing`.
